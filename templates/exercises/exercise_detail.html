Standard Exercises: Find the expected flag in query results.

Anti-Flag Exercises: Some exercises include "anti-flags" - text that must NOT appear in your results for the challenge to be successful. These exercises test your ability to filter queries properly and protect sensitive data.

Examples of anti-flag exercises:

  • Retrieving data while filtering out confidential information
  • Selecting specific columns to avoid exposing sensitive data like passwords
  • Using JOIN operations without revealing protected information

For advanced challenges, JavaScript mode allows you to:

  • Use execQuery(query, params) to run SQL queries
  • Process results programmatically
  • Use techniques like time-based extraction
  • Automate character-by-character password extraction
  • Use console.log() to display output

Example for blind time-based extraction:

// Extract data character by character
for (let pos = 1; pos <= 8; pos++) {
  for (let char of 'abcdefg...') {
    const start = performance.now();
    execQuery('... AND substr(password,'+pos+',1)="'+char+'" AND 1=sleep(0.1)');
    const time = performance.now() - start;
    if (time > 100) console.log('Found:', char);
  }
}
